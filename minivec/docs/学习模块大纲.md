## 模块一:`distance.c`(★☆☆ 热身)

### 要实现的函数(4 个)
| 函数 | 作用 | 一句话 |
|------|------|--------|
| `dist_dot` | 内积 | `sum(a[i]*b[i])`,越大越相似 |
| `dist_l2sq` | L2 距离平方 | `sum((a[i]-b[i])^2)`,越小越相似,不开方 |
| `dist_cosine` | 余弦相似度 | `dot/(|a||b|)`,越大越相似 |
| `vec_normalize` | 原地归一化 | `v <- v/|v|` |

### 核心概念
- 三种度量(内积 / L2 / 余弦)的含义与关系
- **归一化后余弦 = 内积**(性能关键)
- L2 为什么不开方(单调性 → 省 sqrt)
- 除零保护(零向量)

### 验证
写个 `main` 喂两个手算过的向量,核对四个函数输出。

### 对应面试知识分支
**分支 2:相似度度量**

## 模块二:`index_flat.c`(★★☆ 基线)

### 要实现的函数(1 个)
| 函数 | 作用 |
|------|------|
| `flat_search` | 遍历全库,返回最相似的 topK 个 |

### 核心概念
- 暴力检索复杂度 O(N×D)
- **topK 用堆,不用全排序**(O(N log K) vs O(N log N))
- 度量方向统一:COSINE/DOT 越大越好(小顶堆),L2 越小越好(大顶堆)
- 跳过墓碑位(`item.vec == NULL`)
- 结果按相似度排序输出

### 子任务拆解
1. 遍历 `vstore_at(s, 0..count)`,跳过 `vec==NULL`
2. 按 `metric` 调对应 `dist_*` 算分
3. 维护大小为 K 的堆(留住最优 K 个)
4. 取出堆 → 排序 → 写 `out[]`

### 验证
插 5~10 个向量,VSEARCH 几个已知最近邻,肉眼核对。
**这是后面 HNSW 的标准答案,务必先正确。**

### 对应面试知识分支
**分支 3:KNN vs ANN**

## 模块三:`index_hnsw.c`(★★★ 招牌,重点)

### 要实现的函数(5 个 + 2 个建图/查询入口)
| 函数 | 类型 | 作用 |
|------|------|------|
| `random_level` | 内部 | 给新节点抽最高层级(指数衰减) |
| `search_layer` | 内部(心脏) | 在单层里找离 query 最近的 ef 个 |
| `select_neighbors` | 内部 | 从候选里挑 M 个邻居(简单版/启发式版) |
| `hnsw_insert` | 对外 | 建图:抽层 → 逐层连边(双向) |
| `hnsw_search` | 对外 | 查询:顶层粗导航 → 底层精搜 |

### 核心概念
- HNSW = 跳表的升维(分层链表 → 分层图)
- 三参数:`M` / `ef_construction` / `ef_search`
- `search_layer` 三个数据结构:visited / candidates(最小堆)/ result(最大堆)
- 插入两阶段:① 顶层贪心下降定位 ② 逐层连边
- 查询两阶段:① 顶层 ef=1 粗导航 ② Layer0 大 ef 精搜
- **度量方向统一**:内部统一成"距离越小越近"(COSINE/DOT 取负)
- 删除难题(墓碑 + 定期重建)

### 子任务拆解(建议这个顺序)
1. `random_level`(几行,先跑通)
2. 节点的邻居内存布局(`neighbors` 怎么按层切片)
3. `search_layer`(最难,先用数组模拟堆也行,后面再换真堆)
4. `hnsw_search`(基于 search_layer)→ **此时就能用暴力对比 recall**
5. `select_neighbors` 简单版(取最近 M 个)
6. `hnsw_insert`(基于 search_layer + select_neighbors)
7. `select_neighbors` 启发式版,对比 recall 提升
8. 在 `parser.c` 把 `db->index = hnsw_create(...)` 接上

### 验证
- 同一批数据,HNSW 结果 vs 暴力结果,算 **recall@10**
- 调 `ef_search`,画出 recall↑ / 延迟↑ 曲线(简历素材)

### 对应面试知识分支
**分支 4:HNSW 深入**(招牌菜)
